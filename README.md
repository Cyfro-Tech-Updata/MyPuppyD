**MyPuppyD** to narzędzie dla początkujących tunerów umożliwiające edytowanie map kalibracyjnych oraz system ich znajdywania jak i rozwiązań automatycznych.

# 🔄 Strefa aktualizacji (Update Zone)

  ⚠️ Ta sekcja odpowiada za sprawdzanie i zarządzanie aktualizacjami aplikacji.

# 🟢 Jak to działa?

- Aplikacja przy starcie:
  - sprawdza dostępność nowej wersji
  - porównuje wersję lokalną z wersją z repozytorium
- Jeśli dostępna jest aktualizacja:
  - użytkownik otrzymuje powiadomienie
  - możliwe jest pobranie nowej wersji
